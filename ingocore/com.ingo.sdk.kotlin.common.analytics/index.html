object IEventNames

IngoAnalytics
Link copied to clipboard
interface IngoAnalytics

Implement this interface and register it via the SDK builder's analytics(...) option to observe user and application behavior inside the SDK UX. The SDK invokes trackEvent for each tracked event, using the constants in IEventNames, IScreenNames, IPropertyNames, and IPropertyValues as the event vocabulary. Calls are synchronous and blocking, so keep the implementation non-blocking.

class IngoDefaultAnalytics : IngoAnalytics

The no-op IngoAnalytics used when no implementation is provided to the SDK builder's analytics(...) option. Every trackEvent call is ignored. Supply your own IngoAnalytics to receive telemetry.

object IPropertyNames

Catalog of the keys used in the IngoAnalytics.trackEvent properties map. SessionId, CustomerId, and SystemTime (plus TransactionId when applicable) appear on every event; others such as ScreenName, DocumentType, HttpStatus, and PromoCode are added per event. Each constant's value equals its name.

object IPropertyValues

Catalog of the constrained values that appear for specific properties in the IngoAnalytics.trackEvent properties map: DocumentType values (IdFront, IdBack, CheckFront, CheckBack) and FundsTiming values (FundsInMinutes, FundsInDays). Each constant's value equals its name.

object IScreenNames

Catalog of SDK screen identifiers. A screen's constant is reported under the ScreenName key (see IPropertyNames) in IngoAnalytics.trackEvent — for example on the ScreenDisplayed event (see IEventNames) — letting you attribute events to a specific screen. Each constant's value equals its name.
