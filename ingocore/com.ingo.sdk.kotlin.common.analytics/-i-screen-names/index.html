IScreenNames

object IScreenNames

Catalog of SDK screen identifiers. A screen's constant is reported under the ScreenName key (see IPropertyNames) in IngoAnalytics.trackEvent — for example on the ScreenDisplayed event (see IEventNames) — letting you attribute events to a specific screen. Each constant's value equals its name.
