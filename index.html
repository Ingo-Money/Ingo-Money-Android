Module Ingo Money Android SDK

The official Android SDK for Ingo Money — mobile check capture and funding.

Getting started

Configure and launch a session through IngoSdkSession.Builder, then call start:

val session = IngoSdkSession.Builder(context)                // Activity or Application context
    .baseUrl("https://<your-ingo-base-url>")
    .customerId("<customer-id>")
    .sdkAuthorizationToken("<server-minted-session-token>")  // from your server-to-server auth
    .fraudforceDeviceBlackbox(blackbox)                      // from the TransUnion FraudForce SDK
    .activityResultLauncher(launcher)                        // your registered ActivityResultLauncher<Intent>
    // optional customizations: .theme(...), .analytics(...), .isPromoCodeEnabled(false), ...
    .build()

session.start(
    onSuccess = { /* SDK launched */ },
    onFailure = { e -> /* e.g. a missing/blank required value or an invalid base URL */ },
)

Handling the result

The SDK runs in its own activity and returns its outcome through the ActivityResultLauncher you registered with IngoSdkSession.Builder.activityResultLauncher(...). When the flow finishes, your launcher's callback receives an ActivityResult:

  • resultCode is Activity.RESULT_OK for any normal exit — customer close and server declines/errors alike. It is not how you tell outcomes apart.

  • The outcome is a JSON-encoded IngoSdkResult on the result Intent, under the extra key "ingo_sdk_result". Decode it with IngoSdkResultDeserializer and branch on IngoSdkResult.exitCode.

val launcher = registerForActivityResult(ActivityResultContracts.StartActivityForResult()) { result ->
    val json = result.data?.getStringExtra("ingo_sdk_result") ?: return@registerForActivityResult
    val outcome: IngoSdkResult = IngoSdkResultDeserializer.deserialize(json)
    when (outcome.exitCode) {
        "CUSTOMER_EXIT_SDK"                       -> { /* customer closed the SDK */ }
        "TRANSACTION_CHECK_DECLINED"             -> { /* check declined */ }
        "TRANSACTION_LOAD_FAILURE"               -> { /* funding failed */ }
        "CUSTOMER_IDENTITY_VERIFICATION_FAILURE" -> { /* identity (KYC) failed */ }
        "SESSION_TIMEOUT"                        -> { /* session timed out */ }
        else                                     -> { /* handle other / future codes */ }
    }
}

IngoSdkResult also carries customerIdentifier, transactionReferenceNumber, title, detail, and lastModule for display and telemetry.

Exit codes

exitCode is a raw string that mirrors the server's outcome code, so handle unrecognized values gracefully — new codes can appear without an SDK update. The common terminal outcomes:

exitCode Meaning
CUSTOMER_EXIT_SDK The customer closed the SDK.
CUSTOMER_EXIT_UNKNOWN_ERROR An unexpected/unmapped error ended the session.
CUSTOMER_IDENTITY_VERIFICATION_FAILURE Identity verification (KYC) failed.
TRANSACTION_CHECK_DECLINED The check transaction was declined.
TRANSACTION_LOAD_FAILURE The transaction failed to load funds.
TRANSACTION_VOIDED_CHECK_SOFT_DECLINED A voided-check requirement was soft-declined.
DEVICE_VERIFICATION_FAILURE Device verification failed.
SESSION_TIMEOUT The session timed out.
UNAUTHORIZED The request was unauthorized.
INTERNAL_SERVER_ERROR A server-side error occurred.

What's documented here

This reference covers the partner-facing API only:

  • IngoSdkSession and its Builder — the entry point.

  • Results — IngoSdkResult (the session outcome) and IngoSdkResultDeserializer (decode it from the launcher result).

  • Theming — IngoSdkTheme, IngoSdkColorTheme, and IngoTypography.

  • Analytics — IngoAnalytics (implement to receive SDK events) and IngoDefaultAnalytics.

Internal implementation (networking, view models, screen flows, serialization models) is intentionally excluded. For the full integration walkthrough — server-to-server auth, generating the FraudForce device blackbox, and registering the ActivityResultLauncher — see the Android Integration Guide shipped with your distribution.
