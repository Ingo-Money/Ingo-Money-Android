class IngoSdkResult(val exitCode: String, val exitOnUTC: Long, val customerIdentifier: String, val transactionReferenceNumber: String?, val title: String, val detail: String, val lastModule: String) : BaseIngoSdkResult

The outcome of an SDK session, returned to your app as the result payload.

The SDK runs in its own activity; when it finishes it puts a JSON-encoded IngoSdkResult on the result Intent under the key "ingo_sdk_result". In your ActivityResultLauncher callback, read that extra and decode it with com.ingo.sdk.kotlin.common.IngoSdkResultDeserializer, then branch on exitCode. The launcher fires with RESULT_OK for any normal exit — customer close and declines/ errors — so exitCode (not the Android result code) is how you tell outcomes apart.
