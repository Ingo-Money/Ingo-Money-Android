## Installation

The Ingo Money SDK is a set of Maven artifacts. It depends on two third‑party SDKs — **MiSnap** (Mitek) and
**FraudForce** (TransUnion / iovation) — resolved **directly from the vendors' own repositories**. Add the
three repositories below to your `settings.gradle.kts` (`dependencyResolutionManagement { repositories { … } }`).

> **Authentication:** Ingo and Mitek are served from **GitHub Packages**, which requires a **classic**
> `read:packages` Personal Access Token (fine‑grained tokens and GitHub App tokens are rejected). **One token
> covers both.** Create it at *GitHub → Settings → Developer settings → Personal access tokens → Tokens
> (classic)*, then put it in `~/.gradle/gradle.properties`:
>
> ```properties
> gpr.user=<your-github-username>
> gpr.key=<your-classic-read:packages-PAT>
> ```

```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()

        // Ingo Money first-party SDK
        maven {
            name = "IngoGitHubPackages"
            url = uri("https://maven.pkg.github.com/Ingo-Money/Ingo-Money-Android")
            credentials {
                username = providers.gradleProperty("gpr.user").orNull ?: ""
                password = providers.gradleProperty("gpr.key").orNull ?: ""
            }
            content { includeGroup("com.ingo.sdk") }
        }

        // MiSnap (Mitek) — vendor-direct GitHub Packages (same PAT as above)
        maven {
            name = "MitekGitHubPackages"
            url = uri("https://maven.pkg.github.com/mitek-systems/misnap-android")
            credentials {
                username = providers.gradleProperty("gpr.user").orNull ?: ""
                password = providers.gradleProperty("gpr.key").orNull ?: ""
            }
            content { includeGroup("com.miteksystems.misnap") }
        }

        // FraudForce (TransUnion / iovation) — anonymous, vendor-direct raw AAR
        exclusiveContent {
            forRepository {
                ivy {
                    name = "FraudForceGitHubRaw"
                    url = uri("https://raw.githubusercontent.com/iovation/deviceprint-SDK-Android")
                    patternLayout { artifact("v[revision]/[artifact]-[revision].[ext]") }
                    metadataSources { artifact() }
                }
            }
            filter { includeModule("com.iovation.mobile.android", "fraudforce-lib-release") }
        }
    }
}
```

Then add the SDK to your app module (`build.gradle.kts`). MiSnap and FraudForce resolve transitively:

```kotlin
dependencies {
    implementation("com.ingo.sdk:androidsdk:7.2.5")
}
```

> Coordinates are **lowercase** (`androidsdk`, `androidsdkux`, `androidcoreux`, `ingocore`, `sharedsdk`).
> Use the latest version — see the Release badge above.

## Usage

```kotlin
val session = IngoSdkSession.Builder(this) // Activity or Application context
    .baseUrl("https://<your-ingo-base-url>")
    .customerId("<customer-id>")
    .sdkAuthorizationToken("<server-minted-token>")   // single-use, from your server-to-server auth
    .fraudforceDeviceBlackbox(blackbox)               // generated by the TransUnion FraudForce SDK
    .activityResultLauncher(launcher)                 // your registered ActivityResultLauncher<Intent>
    .build()

session.start(
    onSuccess = { /* SDK launched */ },
    onFailure = { e -> /* handle launch failure */ },
)
```

You generate the FraudForce device blackbox yourself using the TransUnion Device Risk SDK and pass it in. See
the full flow — server-to-server auth, generating the blackbox, and registering the
`ActivityResultLauncher` — in the **Android Integration Guide** (shipped with your distribution).
